DUALLENS PROTOTYPE

HOW TO OPEN
1. Unzip the folder.
2. Double-click index.html.
3. The app opens in Microsoft Edge or Chrome.

WHAT IS INCLUDED
- Responsive DualLens home page
- Search and topic filters
- Three sample stories
- Left/right perspective comparison
- Common-ground facts
- Headline comparison
- Narrative-divergence score
- X-ready SVG perspective-card download
- Custom card creator
