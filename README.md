# DualLens Studio

A free, static social-post generator designed for GitHub Pages.

## Files

- `index.html`
- `style.css`
- `app.js`

## Publish with GitHub Pages

1. Create a new public repository named `duallens-studio`.
2. Upload all three files from this folder.
3. Open the repository's **Settings**.
4. Select **Pages** in the left menu.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**.
7. Click **Save**.

Your website will appear at:

`https://YOUR-USERNAME.github.io/duallens-studio/`

## Use

Open the site, change the story fields, choose a format, and click **Export PNG**.
The image will save to your browser's Downloads folder.
